🐍 Mentoria - Exercícios de Lógica e Condicionais em Python
Este repositório contém os exercícios desenvolvidos durante a minha mentoria de programação, focando nos fundamentos da linguagem Python e na construção de raciocínio lógico estruturado.

🚀 O que estou praticando?
Neste repositório, explorei os blocos fundamentais de controle de fluxo e tomada de decisão:

Estruturas Condicionais (if, elif, else): Implementação de decisões no código com base em condições lógicas e operacionais.

Operadores Relacionais e Lógicos: Uso de comparações (==, >, <, >=, <=, !=) e operadores booleanos (and, or, not) para construir regras de negócio dinâmicas.

Entrada e Saída Interativa: Manipulação das funções input() e print() com conversão de tipos de dados (int, float).

🎮 Funcionalidades e Exemplos Práticos
Os scripts abordam situações comuns de tomada de decisão:

Validação de Dados: Verificação de idades, notas escolares ou valores numéricos para determinar aprovações e permissões.

Classificação de Informações: Categorização automática de entradas de acordo com faixas de valores ou critérios específicos.

Controle de Fluxo: Direcionamento da execução do programa dependendo das escolhas informadas pelo usuário no terminal.

🛠️️ Tecnologias Utilizadas
Linguagem: Python 3

Ambiente: VS Code / Terminal
